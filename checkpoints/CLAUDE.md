# checkpoints/CLAUDE.md

Safety rules for checkpoint files. These `.pkl` files are expensive — a full training run takes hours to days on a single GPU. One wrong command wipes that work.

## Never overwrite without a backup

Before running any training script that writes to `checkpoints/`:

1. Check what the script writes (look at its `--save-path` or hardcoded output).
2. If a file with that name already exists, confirm it's already backed up in `run{N}_backup/` **or** the user explicitly said "overwrite".
3. If neither, stop and ask.

We already lost Run 2 and Run 3 checkpoints once by running Run 4 with the same filenames. Don't repeat that.

## Backup folders

| Folder | Contents |
|--------|----------|
| `run2_backup/` | Run 2 MLP populations and egos (multiHRI-matched) |
| `run3_backup/` | Run 3 MLP egos (per-layout H/M/L + eval-based MEP) |
| `run4_backup/` | Run 4 pixel CNN egos |

When wrapping up a run, copy every fresh `.pkl` into its `run{N}_backup/` before any subsequent run starts.

## Naming conventions

| Pattern | Meaning |
|---------|---------|
| `sp_n2_seed{0-2}.pkl` | Self-play ego, 2-player, seed |
| `sp_pop_seed{0-4}.pkl` | SP population (16 agents × 35 ckpts) |
| `sp_pop_seed{N}_layout_scores.pkl` | Per-layout self-play scores for that pop — generated by `evaluate_pop_per_layout.py` |
| `mep{8,16}_pop_seed{0-4}.pkl` | MEP Phase 1 population |
| `mep{8,16}_seed{0-2}.pkl` | MEP Phase 2 ego |
| `mep{8,16}_pop_seed{N}_layout_scores.pkl` | Per-layout scores for MEP pop |
| `bc_seed{0-4}.pkl` | BC partner policies |
| `bcp_n2x1_hetero_seed{0-2}.pkl` | BCP ego |
| `fcp_n2x1_hetero_seed{0-5}.pkl` | FCP ego. Seeds 0–2 are the canonical run; 3–5 exist for Run 4 (pixel) |

`n2x1` = 2 agents, 1 unseen partner. `hetero` = partners independently sampled.

## Reading a checkpoint

Every checkpoint pickle includes `data["config"]`. Always inspect it to decide which network/encoder to load:

- `config["obs_encoding"]`: `"egocentric"` (default) / `"full"` / `"pixel"`
- `config["hidden_dims"]`: MLP architecture (e.g. `(256, 256)`)

Pixel checkpoints use `IMPALACNNActorCritic` with the palette from `ObsEncoder(mode="pixel").atlas.palette`.
